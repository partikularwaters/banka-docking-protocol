# Changelog

All notable behavioral changes to this protocol will be recorded here. Changes
to status meanings, safety gates, the assessment schema, or handoff boundaries
are protocol changes.

## [0.1.0-draft] - Unreleased

### Validation

- Validated the draft against a real brownfield software project.
- Exercised clear-scope assessment, owner clarification, Blocker and Readiness
  requirement reassessment, finding supersession, stabilization separation,
  isolated non-production environment planning, and evidence-first investigation
  of uncertain migration state.
- Confirmed that new owner evidence can narrow, reclassify, resolve, or supersede
  initial findings without weakening retained provenance.
- Confirmed that Docking can stop at `Readiness work required` without performing
  unauthorized repository, deployment, production, or Banka actions.

### Added

- Initial assessment, minimal-readiness, and handoff protocol.
- Independently useful `ADOPTION-ASSESSMENT.md` template.
- Optional, replaceable scope-clarification handoff and external Banka handoff.
- Four fictional examples covering six acceptance scenarios.
- Repository-local integrity check.
